# IoT Based Smart Robot Cleaner

## 📌 Overview
This project was developed as my **Third Year (T.E.) Mini Project** in Electronics & Telecommunication Engineering.  
It focuses on building a **low-cost IoT-enabled smart cleaning robot** using **ESP32, ultrasonic sensor, and L298N motor driver**.  
The robot supports **wireless browser-based control** and **autonomous obstacle avoidance**, making floor cleaning efficient and automated.

## 🛠️ Tech Stack
- **Microcontroller:** ESP32  
- **Sensors:** Ultrasonic sensor for obstacle detection  
- **Motor Driver:** L298N for controlling DC motors  
- **Control Interface:** Wireless browser-based control (IoT integration)  
- **Programming Language:** Embedded C / Arduino IDE  
- **Simulation & Testing:** Hardware prototyping and IoT interfacing  

## 🚀 Features
- Autonomous obstacle avoidance using ultrasonic sensor  
- Wireless browser-based control via ESP32 IoT capabilities  
- Efficient floor cleaning mechanism with DC motors  
- Low-cost design suitable for academic and prototype use  
- Hands-on experience in **embedded systems, IoT, sensor interfacing, and robotics automation**

## 🎓 Academic Details
- **Project Type:** Mini Project (T.E. Academic)  
- **Domain:** IoT & Robotics Automation  
- **Skills Gained:** Embedded systems programming, IoT integration, robotics design, sensor interfacing, automation concepts
